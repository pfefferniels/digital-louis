# Digital Louis renderer

Draws the préludes non mesurés from their MEI encoding anywhere on the
continuum between the editors' measured reading (`t = 0`) and the reading
order of the source (`t = 1`).

```ts
import { prepare, render } from './renderer'

const score = prepare(meiDocument) // everything that does not depend on t
element.innerHTML = render(score, t)
```

`render(score, t, { noteheads: 'unmeasured' })` draws every note as unmeasured
notation writes it, as the Bauyn manuscript does: a semibreve of one size,
ornaments and long notes alike, without stem, flag, beam or dots. The reading
layout always leaves room for heads drawn that way.

The viewer (`src/Work.tsx`) maps its slider onto the continuum: "Mesuré" is
`t = 0`, "Non mesuré" is `t = 1`, drawn with unmeasured noteheads.

## How it works

Each stage is a pure function of the one before; nothing is mutated.

| module | does |
| --- | --- |
| `mei.ts` | reads the dialect into the immutable model of `model.ts`; the only module that touches the DOM |
| `time.ts`, `reading.ts` | notated onsets (exact, `Rational`) and the reading order that `@precedes` describes |
| `staffStates.ts`, `signatures.ts` | the clef and key each staff shows as the piece goes on, and where their glyphs go |
| `analysis.ts` | every head with its staff position, glyph, onset, reading step and stem direction |
| `horizontal.ts`, `spacing.ts` | gives every head two places: one by notated time, one by reading order |
| `staff.ts`, `controls.ts`, `page.ts` | engraves a point of the continuum: `x = lerp(measured, reading, t)` |
| `svg.ts` | writes the page as SVG |

Both layouts space by the same rule: a gap is never smaller than what the
notation needs (`noteheads.ts` computes it with the same functions that later
draw), and otherwise proportional to notated time or to one reading step. The
stretch that fills a system is solved exactly. What the source does not read
(rests, say) and what is placed by time stamp (figured bass, cadence labels)
follows a piecewise linear map from notated time to x, built from the notes it
does read.

On the way between the layouts the heads of a chord part, and they give way
to the right rather than run into one another or each other's accidentals
(`keepApart`), wholly from Jamais d'aplomb (`t = 1/3`) on. An ornament keeps to
the note it leads into, the first of its chord the source reads: it comes up
close to it by Jamais d'aplomb, its grace notes all but touching each other,
follows it wherever it gives way, and only then takes its own place in the
reading.

All layout is in staff spaces, y down. Glyphs come from Leipzig (SIL OFL);
`leipzig.ts` is generated by `tools/renderer/extract_glyphs.py`.

## The SVG

The output keeps the class and data vocabulary the viewer selects by, so
`changeVisibilities`, `insertShadowSemibreves`, the tenue engine and the
facsimile linking work on it unchanged:

`.system > .measure > .staff > .layer.<voice> > .note.<type>` with
`.notehead`, `.stem`, `.accid`, `.dots`, `.flag`; `.beam polygon`,
`.ledgerLines`, `.tie`, `.trill`, `.mordent`, `.harm .fb`, `.dir`,
`.bracketSpan`, `.barLine`, `.clef`, `.pgHead`; `data-id`, `data-corresp`,
`data-precedes`, `data-next`. Glyphs are `<use xlink:href>` elements with
`width` and `height`, each in a `<g transform="translate(x y)">` of its own,
which a browser moves more cheaply than the `<use>` itself.

For the frames of a transition, `draw(element, score, t)` puts the score into
an element of the page and, from the second frame on, changes only what moved
(`patch.ts`), rather than writing the whole SVG anew.

## The dialect

Supported: two or more staves with C, F or G clefs and key signatures of up to
seven sharps or flats; clef and key changes in score or staff definitions
between measures, and clefs within layers; layers as voices; notes (breve to
eighth, dots, written accidentals, grace notes as ornaments, cue size),
chords, rests, spaces, beams, grace groups; ties, trills, mordents, figured
bass (`harm/fb/f`), directions and bracket spans by time stamp; encoded system
breaks. `annot` is ignored.

Ornaments follow the Bauyn manuscript: the tremblement (`<trill>`) is the
short wavy line just above its note, the pincé (`<mordent>`) the wavy line
struck through just below it.

Anything else is reported as `UnsupportedMei`, naming the element, rather
than drawn wrong. Not yet supported: slurs, fermatas, turns, tuplets,
sixteenths, cautionary clefs and keys at the end of a system.
